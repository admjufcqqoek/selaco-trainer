## 📖 About

Selaco by Altered Orbit Studios (Early Access 2023) is a GZDoom-powered FPS inspired by F.E.A.R. You battle intelligent enemy AI that takes cover, calls for backup, and flushes you out with grenades. The environment is fully destructible and every firefight becomes a dynamic improvisation.
